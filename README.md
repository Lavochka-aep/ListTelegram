# ListTelegram - Управляй своим сервером через Telegram!

**ListTelegram** — это не просто плагин для вайтлиста. Это мощнейший комбайн для полного управления вашим Minecraft-сервером прямо из Telegram. От обработки заявок игроков до просмотра консоли в реальном времени — все в вашем телефоне.

---

## 🚀 Ключевые возможности

*   **✅ Система заявок в вайтлист:** Игроки подают заявку через бота, а вы или ваши модераторы одобряете или отклоняете ее одной кнопкой.
*   **🔗 Привязка аккаунтов:** Пользователи могут связать свой игровой аккаунт с Telegram, чтобы получить доступ к персональным функциям.
*   **📊 Профиль игрока и статистика:** Просмотр подробной статистики игрока: общее время в игре, дата первого и последнего входа, а также генерация графика активности.
*   **🌉 Мост чата:** Свяжите игровой чат с любой группой в Telegram. Сообщения будут пересылаться в обе стороны.
*   **🚨 Система жалоб:** Игроки могут быстро подать жалобу на нарушителя прямо через бота.
*   **👑 Админ-панель "Все-в-одном":**
    *   **🔴 Живая консоль:** Просматривайте консоль сервера в реальном времени и выполняйте команды прямо из Telegram.
    *   **🛑 Управление сервером:** Перезапускайте или останавливайте сервер с подтверждением.
    *   **🚫 Управление игроками:** Баны игроков.
*   **💰 Система лицензирования и рекламы:** Встроенная ненавязчивая реклама, которую можно отключить с помощью ключа лицензии. Идеально для коммерческого распространения плагина.

## 🛠️ Установка и настройка

1.  **Скачайте** последнюю версию плагина со страницы Modrinth.
2.  **Поместите** скачанный `.jar` файл в папку `plugins` вашего сервера.
3.  **Запустите** сервер один раз, чтобы сгенерировался файл `config.yml` в папке `/plugins/ListTelegram/`.
4.  **Остановите** сервер.
5.  **Откройте** `config.yml` и настройте его.

### Настройка `config.yml`

Это самый важный шаг.

```yaml
# Включен ли вайтлист при входе на сервер
whitelist:
  enabled: true

telegram:
  # 1. Токен вашего бота. Получите его у @BotFather в Telegram.
  token: "YOUR_BOT_TOKEN"
  
  # 2. ID вашего личного чата с ботом. Это главный администратор.
  #    Узнайте его у @userinfobot.
  admin-chat-id: "YOUR_CHAT_ID"
  
  # 3. (Опционально) ID чатов модераторов. Они будут получать заявки и жалобы.
  moderator-chat-ids:
    # - "ID_МОДЕРАТОРА_1"
    # - "ID_МОДЕРАТОРА_2"
    
  # 4. Имя вашего бота (без @). Будет отображаться в сообщениях.
  bot-username: "YourBotName"
  
  # 5. (Опционально) ID группового чата для моста с игрой.
  #    Добавьте бота в группу и сделайте его администратором.
  chat-bridge-group-id: ""

# (Для владельцев серверов) Сюда вставляется ключ для отключения рекламы.
license-key: ""
```

6.  **Сохраните** файл и **запустите** сервер. Готово!

## 🤖 Использование Telegram-бота

Найдите вашего бота в Telegram и отправьте ему команду `/start`.

### Меню игрока
*   **📝 Подать заявку:** Начинает пошаговый процесс подачи заявки в вайтлист.
*   **👤 Мой профиль:** Показывает вашу игровую статистику и кнопку для генерации графика активности. (Требуется привязка аккаунта)
*   **🚨 Подать жалобу:** Позволяет отправить жалобу на другого игрока.
*   **🔗 Привязать аккаунт:** Выдает уникальную команду `/link <code>`, которую нужно ввести в игре для связи аккаунтов.

### 👑 Админ-меню (Доступно только `admin-chat-id`)
*   **🔴 Консоль:** Начинает трансляцию консоли сервера в одно обновляемое сообщение.
    *   Чтобы **выполнить команду**, просто отправьте ее боту с префиксом `!` (например, `!list`).
    *   Чтобы **остановить трансляцию**, нажмите на кнопку под сообщением.
*   **🚫 Забанить игрока:** Запрашивает ник игрока для бана.
*   **🛑 Остановить сервер:** Требует подтверждения для остановки сервера.
*   **🔄 Рестарт сервера:** Требует подтверждения для перезапуска сервера.
*   **📋 Показать вайтлист:** Присылает список всех игроков в `whitelist.txt`.

---

## 💻 Команды в игре

*   `/link <code>` - Привязывает ваш аккаунт к Telegram.
*   `/lt help` - Показывает список всех доступных команд для администрации.
*   `/lt reload` - Перезагружает `config.yml`, `whitelist.txt` и лицензию.
*   `/lt importstats` - **(Выполняется один раз!)** Импортирует старую статистику времени игры из файлов Minecraft.
*   `/lt importvanilla` - Импортирует всех игроков из стандартного `whitelist.json` в `whitelist.txt` плагина.
